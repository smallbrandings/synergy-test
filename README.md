# 시너지 테스트

GitHub Pages용 정적 웹사이트입니다.

## GitHub Pages 배포 순서

1. GitHub에서 새 저장소를 만듭니다. 저장소 이름은 `synergy-test`처럼 정하면 됩니다.
2. 저장소 화면에서 **Add file → Upload files**를 누릅니다.
3. 이 폴더 안의 `index.html`과 `high-five.png` 두 파일을 함께 올리고 **Commit changes**를 누릅니다.
4. 저장소의 **Settings → Pages**로 이동합니다.
5. **Build and deployment**에서 `Deploy from a branch`, `main`, `/(root)`를 선택하고 저장합니다.
6. 잠시 후 표시되는 주소로 접속하면 사이트가 열립니다.

`high-five.png`는 시작 화면에 사용되는 이미지라서 반드시 `index.html`과 같은 폴더에 올려야 합니다.
